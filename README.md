專題心得

透過這次電影管理平台的開發專案，我學習到如何運用 ASP.NET Core MVC 架構建立一個具備基本功能的電影商城，並將課堂上學到的程式設計與資料庫知識實際應用於專案中。在開發過程中，我完成了電影資料的新增、查詢、修改與刪除（CRUD）、使用者登入、購物車、訂單管理等功能，並透過 Entity Framework Core 連接 SQL Server，實現系統與資料庫之間的資料存取。

在這次專案中，我不僅加深了對 C#、MVC 架構、Razor View、SQL 資料庫及前後端整合的理解，也學習到如何透過 Controller、Model 與 View 的分工，讓程式架構更加清楚。此外，開發過程中遇到的路由設定、登入狀態管理、資料庫操作及程式錯誤等問題，讓我體會到軟體開發不只是撰寫程式碼，更需要具備分析問題、查找原因、測試功能及持續修正的能力。

對未來而言，這次專案累積的實作經驗，能幫助我在學習更進階的網頁開發、資料庫設計及系統整合時建立更扎實的基礎。同時，完成一個具有實際功能的網站，也讓我更了解軟體開發的完整流程，並能作為未來求職時展示個人技術能力的作品。未來我希望持續精進程式設計能力，學習更多開發工具與技術，並將所學應用於更完整、更貼近實際需求的系統開發中。
